# Análise de obra paga

Confronta, serviço a serviço, o que foi **apontado** na obra com o que foi **pago**.

- **Entra:** o PDF da *Medição de Mão-de-Obra* (Energisa) e o `.xlsx` do *fechamento
  simplificado* da obra. Pode entrar mais de um PDF — as parcelas somam.
- **Sai:** quanto foi apontado, quanto foi pago, a diferença, e cada serviço
  classificado como pendente, parcial, pago a mais, pago sem apontamento ou conferido.
  Com busca, filtros, CSV e impressão.

Página única, sem dependências e sem servidor. **Os arquivos são lidos dentro do
navegador — nada é enviado para lugar nenhum.**

Acesso: https://teccelia2001-ux.github.io/analise-obra-paga/
